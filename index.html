ABOUT THE PROJECT

Built to Understand Your Placement Potential

Placify is a basic college placement prediction system designed to help students understand their estimated placement potential using academic performance, technical skills, projects, internships and other relevant factors.

This project was developed as a learning project to explore frontend development, JavaScript, backend concepts and data-driven prediction systems.
